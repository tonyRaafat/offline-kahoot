# 06: Quiz editor

**What to build:** a browser-based quiz editor backed by the storage from ticket 05.

**Blocked by:** 05 (store and select quizzes)

**Status:** ready-for-agent

- [ ] Editor can create, rename, and delete quizzes
- [ ] Editor can add multiple-choice questions with 2–4 options and one correct answer
- [ ] Editor can add true/false questions
- [ ] Editor can set a per-question timer (default 20 seconds)
- [ ] Changes persist to the quiz files and appear in the host's quiz list
- [ ] Editor validates input (requires a correct answer and 2+ options)
