# 04: Play a complete question cycle to a leaderboard

**What to build:** the end-to-end gameplay loop for one quiz, driven by an in-memory sample quiz.

**Blocked by:** 03 (join a game and see a live lobby roster)

**Status:** ready-for-agent

- [ ] Host starts a quiz from an in-memory sample quiz
- [ ] A question with its countdown appears on the host screen and each player's phone
- [ ] Each player can submit exactly one answer per question before the timer ends
- [ ] Late answers are rejected
- [ ] Host reveals the correct answer; players see whether they were correct
- [ ] A leaderboard appears showing speed-based scores after each question
- [ ] Players who briefly lose Wi-Fi auto-reconnect without losing their place
- [ ] The host advances to the next question until the quiz is complete
