# 05: Store and select quizzes

**What to build:** quiz persistence as one JSON file per quiz, a seed sample quiz, host-side quiz selection, and import/export.

**Blocked by:** 01 (launch an offline-reachable game server)

**Status:** ready-for-agent

- [ ] Quizzes are stored as one JSON file per quiz
- [ ] A seed sample quiz ships with the project
- [ ] The host can browse the list of quizzes and select one to play
- [ ] A quiz can be exported to a JSON file and imported back
- [ ] Imported quizzes validate against the agreed quiz shape and reject malformed input
- [ ] Quizzes persist across server restarts
